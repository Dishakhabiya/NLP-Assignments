# NLP Assignments & Experiments

A collection of Natural Language Processing implementations, experiments, and coursework covering text preprocessing, corpus analysis, WordNet, language modeling, text summarization, Named Entity Recognition, UMLS mapping, and speech translation.

The repository demonstrates practical work with classical NLP techniques as well as transformer-based approaches.

---

## Topics Covered

- Text preprocessing and normalization
- Tokenization and linguistic analysis
- Stopword removal, stemming, and lemmatization
- Corpus exploration and analysis
- WordNet and IndoWordNet
- N-gram language modeling
- Gensim and Bag-of-Words
- Phrase and corpus analysis
- Text summarization
- Named Entity Recognition (NER)
- UMLS concept mapping
- Transformer-based speech translation
- Audio quality evaluation
